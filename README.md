# 海外安全官指挥术语系统

一个专为海外安全官、护卫、应急小组设计的**交互式 100 词指挥术语**网页应用。支持手机端快速查询、数据维护、夜视模式等功能。

![项目预览](https://via.placeholder.com/800x450/001a00/00ff41?text=海外安全官指挥术语系统)  
*(建议在此处替换为实际截图)*

## ✨ 主要功能

- **完整 100 条术语**：包含指挥与身份、行动指令、战术方位、装备资源、应急状态、协调日常六大类
- **智能搜索**：支持中文、音译、斯瓦希里语/参考词模糊搜索
- **分类筛选**：快速切换不同场景类别
- **数据管理**：新增、编辑、删除、自助维护
- **夜视模式**：绿色矩阵风格，适合夜间或低光环境使用
- **数据持久化**：使用浏览器本地存储，刷新不丢失
- **CSV 导入/导出**：方便备份、批量修改和跨设备同步
- **完全响应式**：手机、平板、电脑均优化

## 🚀 快速部署（GitHub Pages）

1. 在 GitHub 创建一个新仓库（推荐公开）
2. 将 `index.html` 和 `README.md` 上传到仓库根目录
3. 进入仓库 → **Settings** → **Pages** → Source 选择 `Deploy from a branch` → main → Save
4. 部署完成后即可通过 `https://你的用户名.github.io/仓库名/` 访问

## 📱 使用说明

### 基本操作
- **搜索**：在顶部搜索框输入关键词（支持中文、音译）
- **筛选**：通过下拉框选择分类
- **新增术语**：点击 **“新增”** 按钮
- **编辑**：点击每行右侧 ✏️ 图标
- **删除**：点击每行右侧 🗑️ 图标
- **夜视模式**：点击右上角 **“夜视模式 ON”** 按钮切换（推荐夜间或战术使用）
- **导出数据**：点击 **“导出CSV”** 备份
- **导入数据**：点击 **“导入CSV”** 恢复或批量添加

### 快捷键
- `/` ：快速聚焦搜索框

### 手机端推荐
- 可添加到手机主屏幕（Chrome/Safari → 添加到主屏幕），使用体验接近原生 App

## 📋 数据结构

每条记录包含以下字段：
- **类别**（六大类）
- **序号**
- **中文意义**
- **斯瓦希里语/参考词**
- **推荐音译**

## ⚠️ 注意事项

- 数据保存在浏览器本地，**清除浏览器缓存会导致数据丢失**（请定期导出备份）
- 目前为单文件版本，适合个人/小团队使用
- 所有功能无需服务器，可离线使用
